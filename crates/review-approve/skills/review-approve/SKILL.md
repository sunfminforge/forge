---
name: review-approve
description: Use when a warden's review of a task passed and the task's pull requests are to be approved: one command runs guild task review --pass and then guild pull approve for each pull, stopping at the first failure.
---

Run `review-approve --help`, then `review-approve pass --help`, before the
first run; the help is the whole manual. Through Guild: `guild tool review-approve …`.
